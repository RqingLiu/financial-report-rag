## Initial design

- `planning.py`: Pydantic request/entity/need/task/plan contracts; company catalog from manifests, SEC submissions and optional registry; generic ASCII-boundary checks; LLM JSON and business validation. Let the model map unknown aliases while rules guard confirmed scope, without a finance glossary. Separate disclosure cutoff, fact year and report year.
- `planned_retrieval.py`: Call existing parameterized Repository.search with validated document IDs; bypass legacy company regex/glossary. Do not load all Blocks/trees; batch-fetch Blocks by ID when needed. At most 2 vector variants/task, grouped candidates and configurable global quotas. Cache actual query vectors.
- `context.py`: Deduplicate source spans and select within task/period budgets. Expand compact tables from the same source with original spans and actual token recounting; retain 10 items/8K. Large tables keep row chunks; row/column semantics and OCR remain unresolved.
- `pipeline.py`: New explicit CLI/service saves plan, retrieval and raw candidates before comparison. Compare dense/equal-RRF/weighted-RRF/context on identical candidates. Preserve old baseline bytes; use unique run directories and existing trace browser/scorer.
- `answering.py`: Generate structured answers per runtime need, valid citation IDs and gaps limited to current context. Failed retrieval is not “not disclosed.” Validate completeness/citations/truncation. Model arithmetic is unverified until deterministic tools exist.
- `generation.py`: Add controlled json_object/purpose options to the existing budget client while preserving baseline compatibility. At most one traced JSON repair for schema/business errors, no service retry; persistent invalidity returns error without wider-scope fallback. Retain usage and pricing basis.
- `configs/companies.json`: Move collection CIK/name/optional aliases from code to metadata. New-company registration needs no algorithm edits; new report years/issuers enter the catalog from metadata. This does not prove correct FY/header interpretation.
